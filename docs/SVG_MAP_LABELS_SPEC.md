# SVG 지역명 표시

FR-SVG-MAP-LABEL-001 / TC-SVG-MAP-LABEL-001. 기존 SVG_MAP_REDESIGN_SPEC에 추가한다.

- 현재 2026-04-01 GeoJSON properties.name/code/parentCode를 그대로 사용한다. 전국17시도, 선택시도 소속 모든시군구의 전체한글명을 SVG text/tspan으로 표시한다. 새로운 지역명/약칭/좌표를 만들지 않는다.
- 공통 d3 Mercator와 실제 geometry에서 기준점을 구한다. MultiPolygon은 가장큰육지polygon을 선택하고 centroid가hole/바다이면 같은polygon의 내부구간으로 보정한다. 제주/울릉 및 독도포함다중섬의 라벨을 바다중심에 두지 않는다. 기준점은 geometry별캐시하며 경계원본은 바꾸지 않는다.
- 화면상의 작은지역부터 전체라벨이 겹치지 않는 가까운위치를 찾는다. 긴행정명은 전체글자를유지한 줄바꿈, 화면글자10~14px의 차분한sans-serif와밝은halo를사용한다. 작은지역/수도권처럼 글자전체를지역안에 넣을수없으면 인접여백과가는연결선을허용한다. 지리기준점은항상해당geometry안이며 가장가까운다른지역으로배정하지않는다.
- 확대/이동/resize시 현재투영의기준점을사용한다. 글자크기는화면기준범위로유지하고라벨이경계와함께이동한다. 화면밖지역은라벨도화면밖이며화면가장자리로강제집합시키지않는다. 최소화면에서는충돌최소배치를사용하고기존접근가능지역목록도유지한다.
- 라벨/연결선은pointerEvents=none으로기존지도tap/hover/pan/pinch/보정과키보드지역목록을가로채지않는다. 방문/선택fill·scope/RLS·좌표저장·카메라/복귀·Native공통렌더링계약은유지한다. DB/API/의존성변경없음.

검증: 실제272개geometry의기준점내부/이름일치·섬/hole·결정적충돌배치, 전국17/서울25/부산16/제주2/경북울릉군등현재데이터의모든시도별이름,320/390/1440실SVG bbox겹침·가시성·확대와글자위클릭/기존방문색회귀. Native공통SVG SSR/타입검사는실기기수용과구분한다. t14계획/제품리뷰후관련focused를실행하며실휴대폰/운영배포를자동승인하지않는다.

수용 해석: 낮은 높이/좁은 화면에서는 지도 내부 전체글자수용이나 모든 viewport 겹침0을 보장하지 않는다. 전체이름/10~14px/지도입력/접근가능목록은 유지하고 실제잔여충돌·여백이동은관측값으로 기록한다. 현재 검증한320서울/경기도는bbox겹침0이며낮은 actual앱의연결선배치가늘어나는한계는TEST_CASE에기록한다. Native공통SSR과실제Native글자렌더는분리한다.
