## t14 사전 보강
대표 정렬 대상은 travel_records.created_at desc,id asc이고 해당 기록의 기존 is_cover 사진을 사용한다. photos.created_at으로 대표를 바꾸지 않는다. 군집 목록도 같은 기록 정렬이다. sheet는 ID만 보관하고 매 조회의 최신 payload로 재해석한다. 삭제/private전환으로 빠진 기록은 즉시 제거하고 모두 빠지면 닫는다. 관계해제 대상은 관계 재조회 후 mine 복귀. 전환/갱신 세대가 지난 목록·cover·상세 오류는 UI에 게시하지 않는다. 로딩/오류는 확정0이 아니며 오류시 이전 친구 사진을 계속 노출하지 않는다. signed URL/다운로드의 즉시 회수는 보장하지 않는다. guest/대상미선택에는 전체공개 list(undefined)를 호출하지 않는다.

상세 경계는 한 축 유효영역(각 변에서32px제외) 점유율85%에서 진입하고65% 미만에서 해제한다. 긴 형태의 지역도 fit 후 상세에 진입한다. 기존 조건부 하단record목록은 요약sheet로 대체하고 지역도감 버튼은 고정높이로 지도 viewport를 보존한다. other는 실제code가 아닌 명시 미배정 필터이며 province를 해제한다.

짧은 가로 화면에서는 wide 보조 패널 전체를 하나의 세로 스크롤로 제공해 상단 도구가 지역 선택을 가리지 않게 한다. 기존 지역 목록 offset 복원을 해당 패널이 소유하며 좁은 화면의 가로 지역목록은 유지한다. 지도 크기/카메라/원본 geometry에는 보조 패널 내용 높이를 반영하지 않는다.

320px 실제 앱에서 보조 영역 높이가 줄어드는 경우에도 외부 세로 ScrollView가 도구를 소유한다. narrow의 지역목록은 그 안의 가로 ScrollView로 x offset을 유지하고, wide는 기존 단일 세로 y offset을 유지한다. 축소된 영역에서 출처/다른 버튼이 겹쳐 입력을 가리지 않도록 자연 콘텐츠 높이(사진56px/지역64px)를 유지한다.

최소화면 라벨은 SVG_MAP_LABELS_SPEC의 충돌최소 예외를 유지한다. 연속지도는 인접시군구가 함께 표시되어320px 경기fit에서 잔여7쌍을 관측했다. 사진·글자를 숨기거나10px미만으로 줄이지 않으며 실제값/스크린샷을 기록하고, 해당 한계를 시각적 무충돌 수용으로 확대하지 않는다.
