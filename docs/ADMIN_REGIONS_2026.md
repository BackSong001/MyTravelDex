# 행정구역 갱신 검증 (2026-11-18)

> 최신 작업 상태(2026-11-19): 공식 2026-11-09 SIG 기반 경계를 로컬 앱에 적용하는 후속 검증을 진행했다. 원본/명칭 오류를 보정하고 공식 EMD·국토지리정보원 자료의 일치 근거로 겹침232쌍의 일부 약219,682㎡를 정리했다. 514쌍은 불확실성을 보존하여 GPS 자동배정하지 않는다. DB/사진/이전 스탬프 파일은 변경하지 않는다. 아래 최초 감사의 미확보·보류 설명은 당시 이력이며 최종 실행 결과와 보정 보고서를 함께 읽는다.

## 적용 계약

FR-ADMIN-2026-001 / TC-ADMIN-2026-001. 갱신일과 경계 기준일을 구분한다. 전국 경계·법정동 코드·출처·좌표계가 검증되기 전에는 운영 자산을 교체하지 않는다. 공식 행정기관 코드는 법정동 코드로 간주하지 않으며 출장소와 일반구를 구별한다. 지도·도감·추첨은 동일한 검증 경계를 사용해야 한다.

FR-ADMIN-2026-002 / TC-ADMIN-2026-002. GPS 공간 판정은 유일한 포함 지역만 확정하며 경계 중복·경계선·좌표 누락은 검토 대상으로 남긴다. 원래 좌표·주소·사진 경로·기록·친구 정보를 수정하지 않는다. 이전 스탬프와 새 행정구역 수집 상태는 분리한다. 일반 시의 구와 특별·광역시 자치구는 도시 단위, 광역시 군은 독립 후보, 제주 두 행정시는 독립 후보로 균등 추첨한다. 통합특별시의 옛 광주 5개 구만 광주 여행지로 묶는다.

## 기존 구조 분석

- 실제 홈은 OpenFreeMap/MapLibre와 SVG 전국 행정지도, 비홈은 React Native SVG/d3-geo다. 렌더러 전환은 이번 범위가 아니다.
- `frontend/src/regions.ts`: `maps/korea-sido.json`, `maps/korea-sigungu.json`의 2026-04-01 SGIS 가공 경계(17/255). `regionAt`는 경계 중복에서 코드순 첫 항목을 선택한다.
- `destinationDraw.ts`: 별도의 2018 KOSTAT `korea-districts.json` 250개, `destinationUnits.ts`에서 167개 여행지로 묶는다. 서로 다른 코드 체계가 혼재한다.
- `provinces.ts`: 법정지역 접두어를 기존 KR-* 내부 ID에 연결한다. GPS로 도감/스탬프를 계산한다. 강원 51→KR-42, 전북 52→KR-45, 세종 36→KR-50, 제주 50→KR-49이므로 접두어를 그대로 대체하면 안 된다.
- `StampCatalog.tsx`, `Social.tsx`: 17개 고정 분모. 별도 행정 스탬프 획득 테이블은 없고 본인 complete 기록의 위치로 집계한다. badge_*는 별도 상품 기능이다.
- 저장소 SQL의 locations는 latitude/longitude, country_code/name, region_name, city_name을 저장한다. 행정구역 코드 컬럼은 없다. 원격 실데이터·스키마는 아직 조사하지 않았다.
- 마커는 기록 원좌표, 선택/확대는 경계 fit, 지역 클릭은 공간 판정. 경계 파생물은 해안 차폐·해양 이미지·경기도 시 union·본토/먼섬 index·라벨 육지 필터까지 재생성해야 한다.

## 데이터 보존 및 전환 게이트

1. 원본 hash/게시일/기준일/좌표계/인코딩/이용 조건과 코드 목록을 버전 manifest에 보관한다.
2. 후보 디렉터리에서 변환한다. 전국 코드 집합·중복·Polygon 유효성·섬 보존·시도 union·해안 중복을 검사하고 검증 실패 시 운영 파일을 쓰지 않는다.
3. 기존 두 버전과 새 버전의 공간 비교표(동일/명칭/이관/분할/통합/불명)를 생성한다. 코드 동일성만으로 경계 동일성을 추론하지 않는다.
4. 원격 변경 필요 시 먼저 백업 보존위치·복원 시험·행 수/ID/사진 경로/좌표 비교를 확인한다. 공개 기록만으로 전체 사용자 데이터 보존을 판정하지 않는다.
5. 기존 기록에는 UPDATE/DELETE가 필요하지 않다. 새 판정은 버전별 파생 결과로 보관한다. DB 영속 스냅샷을 도입하면 owner RLS 및 unique(record_id, version)으로 재실행 가능하게 하고 별도 migration을 검토한다. 운영 적용은 승인 후 수행한다.
6. 과거 스탬프는 구 경계 판정을 별도로 유지하고 최신 수집률 분모와 합산하지 않는다. 모호한 위치는 임의 배정하지 않는다.
7. 검증 후에만 자산과 manifest를 함께 전환한다. 실패 시 이전 앱/자산으로 되돌리며 기존 기록과 sequence를 초기화하지 않는다.

## 2026-11-19 공식 원본 추가 조사

[브이월드 법정구역정보 NA21](https://www.vworld.kr/dtmk/dtmk_ntads_s002.do?svcCde=NA&dsId=21)에서 국토교통부 전국 전체본(기준 11월9일, 게시 11월13일, 120MB)과 이후 11월10일·12일·16일 기준 변동본을 사용자 로그인 후 다운로드했다. 배포 좌표계 메타데이터는 EPSG:5186, 전체 월간/변동 일간, CC BY다. SIG 원본 PRJ는 EPSG:5186으로 식별되며 CPG는949(CP949)다. ZIP/구성파일 SHA256을 보관했다. 데이터 식별자와 날짜는 `admin-boundary-source-audit.json`에 기록했다. 11월18일 이전에 게시된 자료만 대조 후보로 삼았다.

전체본에 변동본을 단순 합치지 않는다. 컬럼 정의와 추가/수정/삭제 의미를 확인한 뒤 순서대로 적용해야 한다. 공개 문의 목록에는 대구 남구 누락/부산 남구 중복 관련 항목도 있으므로 공식 자료라는 이유만으로 완전성을 가정하지 않고 실제 코드·기하를 검사한다.

[연속수치지형도 MK30252](https://www.vworld.kr/dtmk/dtmk_ntads_s002.do?svcCde=MK&dsId=30252)의 9월21일 갱신 파일은 운영자 10월7일 답변상 2025년 구축 자료다. 게시일을 경계 기준일로 오인하지 않고 최신 대조 대상에서 제외했다. [LX 자료](https://geomarket.kr/user/dataset/view.do?data_sn=159)도 게시일이 2024년11월11일이므로 현재 경계 교체 근거로 사용하지 않았다.

이번 후속 작업에서는 앱 경계·manifest 기준일·사용자 DB를 변경하지 않았다. 공식본은 확보·대조했으나 아래 품질 문제로 앱 전환 수용을 통과하지 못했다.

### 원본 검사 결과와 채택 판단
