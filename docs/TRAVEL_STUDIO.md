# 사진으로 여행 쓰기

새 기록은 사진 → 여행 정보의 두 단계다. 사진 목록은 OS 이미지 선택, 포토는 촬영을 연다. JPEG/PNG를 원본 EXIF 검사 후 누적하며 유효 사진 중 빈자리까지만 담는다. 신규 작성은 5장, 저장된 구형 초안과 서버는 20장 계약을 유지한다. 초과는 짧은 진동과 사라지는 안내로 전달한다. 사진·세션 수명, 취소, 파일별 거부, 업로드 UUID와 비공개 초안 정책을 유지한다.

사진 순서의 첫 GPS 및 날짜 최솟값·최댓값을 제안한다. 달력 한 달 이상(월말 보정)은 적용 또는 수동 수정을 받는다. 서로 다른 도시가 확인되면 대표 사진 위치를 고른다. 원좌표를 보존하며 수동 입력은 후속 응답이 덮지 않는다. 새 기록은 공개 기본, 이름·평은 선택이며 완료 후에만 피드에 노출한다.

전국 기본 구도, 한국만 상세 타일, 북한·중국·일본 윤곽·대표 지명과 권한 있는 기록 핀을 공통 Web/Android 카메라에서 표시한다. 홈은 선택한 여행 마스코트와 퍼즐·통계·작성 바로가기를 제공한다. 지도 왼쪽 하단은 실제 표시 출처, My는 라이선스 전문을 제공한다.
