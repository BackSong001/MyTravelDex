# 여행가봥 첫 여행 체험 개선

2026-11-27 종료한 MOAI 동서대학교 광장 대회의 팀 PDF(63쪽), 받은반응 CSV, 보고서 JSON을 비교했다. 새 사용자가 어디에서 멈추는지 확인하고 이를 refactor 브랜치의 수용 기준으로 옮겼다.

일별 ‘써봄’과 CSV의 ‘써 봄’은 서로 다른 집계다. CSV는 일반 패널 3,358행, 대학생 패널 346행, 실제 방문객 분류 2행이다. 각 행을 고유 고객으로 간주하지 않는다. 원자료는 대회 시점의 관찰이므로 이미 수정된 결함도 현재 refactor에서 다시 확인한다.

## 인수 범위

1. 게스트가 여행지를 지도에서 확인한 뒤 공개 사진 날짜와 제주 스탬프까지 이어 간다.
2. 사진이 늦게 뜨거나 기록이 없어도 남은 체험을 계속할 수 있다. 지역 모양을 열어 보는 행동은 본인 획득 이력에 영향을 주지 않는다.
3. 소개 웹에서 여행 사진 기록의 구체적인 결과와 로그인 경계를 확인하고 웹앱 체험을 시작한다.
4. 내 사진을 기록할 때 자동 채움·수동 보완·공개 범위를 이해할 수 있다. 기존 업로드와 초안 복구를 사용한다.
5. 기록 완료 뒤 같은 여행을 내 지도에서 찾아 사진과 장소가 어떻게 연결되는지 확인한다. 기존 갤러리로 충분하다는 117건과, 사진 한 장이 지도에 반영되는 결과를 확인하고 싶다는 멘토 조언이 근거다.
6. 공개 완료한 여행 하나를 가족에게 보내 새 게스트 세션에서 볼 수 있게 한다. CSV ‘끌린 대목 / 이랬으면 봤을 것’에서 ‘가족’이 포함된 575행 중 ‘공유·나누·나눌·같이 보·함께 보·함께 볼·같이 볼·보여’ 중 하나도 포함된 행은 134개다. 문구의 중복을 허용한 단순 부분문자열 집계이며, 134명의 실제 수요를 뜻하지 않는다.

세부 계약은 [요구사항](REQUIREMENT.md), [제품 흐름](PRD.md), [기술 계약](TRD.md), [API](API_SPEC.md), [수용 시나리오](TEST_CASE.md)를 따른다. 화면 디자인은 t12가 결정한다. 리뷰는 모바일·데스크톱 웹의 실제 상호작용과 접근성, 실패 복구, 데이터 공개 범위를 확인한다. Android 수용 여부와 운영 성과는 별도 검증 대상이다.

## 구현 전 독립 리뷰

- 기본 Local 포트 54321은 다른 프로젝트가 점유했다. MyTravelDex 전용 로컬 스택 55321에서 기존 TC-SNS-002의 실제 HTTP 공개 피드·페이지 조회를 통과했다. 운영 배포본을 검증한 결과가 아니다.
- 같은 격리 스택에서 기존 photo.test.ts 중 사진 메타데이터, 초안 재시도, 사진에서 얻은 날짜와 위치, 공개 응답 필드, 완료 저장·목록·날짜 HTTP 16건을 통과했다. 임시 테스트 사본에서 CLI 작업 디렉터리와 대상 포트만 격리 스택에 맞췄으며 앱 코드와 검사 단언은 원본을 사용했다.
- 기존 작성 화면은 새 초안을 public으로 시작했으나 PRD 및 작성기 회귀 기준은 private다. 첫 기록 검수에서 새 작성과 기존 초안 재개를 나눠 검증한다.
- 게스트 도감 이식 후보는 지리 윤곽만 보여 주고 실제 스탬프 미리보기를 숨겼다. 제주 미리보기 자산을 확인하고, 게스트에게 빈 개인 수집 탭을 제공하지 않도록 구현 담당자에게 반환했다.

## 게스트 체험과 소개 웹 리뷰

- 04b2b4d의 게스트 웹 8건을 독립 재실행했다. 390px와 1280px에서 강원권 위치, 게시일과 다른 실제 여행 기간, 사진 디코딩, 제주 그림과 미리보기 표시를 확인했다. 320px 확대 글씨와 사진 서명·이미지 실패 복구도 통과했다. 공개 피드 응답에는 재현 가능한 대역을 사용했다.
- 별도 브라우저 검사에서는 390px·1280px에서 피드 요청 503 → 키보드 재시도 → 빈 목록 → 제주 그림 → 브라우저 뒤로 가기 순서를 통과했다. Android mytrveldex 에뮬레이터의 Chrome 158, 411×810에서도 강원 양구군 → 지도 위치 → 다일 사진 → 제주 그림을 확인했다. 이 검사는 모바일 웹에서 실행했다.
- 소개 웹 원본 생성기를 다시 실행했을 때 파일 차이가 없었다. 정적 Expo export에서 Vercel 규칙으로 직접 접근한 /explore/random이 404여서 수정을 요청했다. 수정한 규칙으로 첫 체험·다시 불러오기·작성 로그인과 누락 정적 자산 404를 확인했다. 소개 웹의 키보드 링크와 JS 없는 페이지도 로컬에서 검증했다.
- 8d56f78의 첫 기록 웹 2건을 독립 재실행했다. 격리 Local Auth·DB·Storage에서 날짜·GPS 자동 입력, 누락 시 직접 보완, 공개 초안 재개, 비공개 완료를 확인했다. 장소 검색 응답은 대역으로 제공했다. 지도 화면의 작성 버튼을 직접 누른 경우에는 로그인 뒤 복귀 의도가 사라져 FR-MOAI-004 후속 수정을 요청했다.

제품 커밋 704f3b3을 포함한 최종 Expo Web export에서 첫 기록 3건, 게스트 전체 여정 2건, 공개 링크 2건을 함께 재실행해 7건 모두 통과했다. 이 숫자는 위 검사의 통합 재실행이므로 합산하지 않는다. 기존 SNS 탐색·피드 날짜·공개 링크 회귀 4건과 프론트엔드 타입 검사도 통과했다. 2026-11-28에 t12에 리뷰 승인을 전달했다.

수용 범위는 refactor 브랜치의 구현과 로컬 검증이다. 실제 Google 동의, Android 네이티브 앱·실기기 공유 시트, 운영 배포와 후속 MOAI 중도 종료율은 검증하지 않았다.
