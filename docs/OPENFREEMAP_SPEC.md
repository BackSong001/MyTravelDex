# OpenFreeMap Positron 홈 전환 (FR-MAP-OFM-001 / TC-MAP-OFM-001)

2026-11-17 사용자 승인 계획. 홈만 Geoapify 타일에서 OpenFreeMap Positron으로 전환한다. Web 검증 후 Android 같은 스타일/카메라를 검증한다. 검색 Geoapify/비홈 SVG/DB/RLS/원좌표/친구 scope는 보존한다.

## 표시와 입력
- 최초/홈/대한민국은 기존 전국fit, 단색하늘색·육지·17개 시도선·사진/숫자만 표시한다. 지도지역명/지형은 숨긴다. 무타일은 화면 표시의 의미이며, 뒤의 유지된 렌더러가 타일/폰트를 요청할 수 있다. 네트워크요청0을 보장하지 않는다.
- 수동 확대는 fitZoom+1에서 상세 진입, fitZoom+0.5 이하에서 전국복귀/선택해제한다. 중간은 직전 표시를 유지한다. 명시 선택 fit 중에는 축소판정하지 않으며 작은 배율의 큰도 전체fit도 상세로 표시한다. 사용자 축소만 선택 강제를 해제한다.
- 전국 보기에서 시·도 경계, 해당 대표사진 또는 목록을 선택하면 520ms 동안 서서히 가속·감속해 시·도 전체를 16px 여백으로 맞춘다. 그 밖의 선택과 전국 복귀는 350ms, 동작 줄이기 설정에서는 즉시 이동한다. 다른시도 사진은 먼저 그 시도로 이동, 같은선택시도의 사진 재클릭은 최신ID 요약이다. 좌표군집은 시도별로 나누고 같은좌표 기록은 모두 유지한다. 비홈 군집은 기존대로다.
- 원래 512zoom↔d3scale/무회전·무기울기/18상한/국내center bounds/동작줄이기/RAF취소·상세복귀를 보존한다. 표시단계도 navigation snapshot에 보관하여 동일배율 예외를 복원한다.
- 포인터와 접근성 사진목록은 같은 선택동작/대상이름을 사용한다. 시도 클릭은 확대상태에서도 시도전체를 fit한다. 기존 시군구 도감필터는 유지한다.

## 렌더러와 자료
- 공식 Positron JSON을 출처/취득일/hash와 로컬 고정한다. Web/Native 같은 스타일로 API키없이 표시한다. 기존 map key는 새 런타임에서 사용하지 않으며 서버검색비밀은 그대로다.
- 전국의 불투명SVG 배경과 상세타일 표시만 전환하며 지도instance/style을 반복재생성하지 않는다. 렌더러생성/스타일실패는 단색SVG+수동retry, 일반타일오류는 안내하며 사진/요약/카메라를 보존한다.
- Positron의 실제도로/수계/녹지·줌별지역명, 한글우선(name:ko→name), POI·행정경계선 제거를 적용한다. 기존 SVG홈라벨은 중복표시하지 않는다. 비홈라벨은 유지한다.
- 원본17육지의 union을 표시전용 사전생성하여 외부영역을 차폐한다. 원본hash/유효성 검증, 런타임union없음, 섬/hole을 보존한다. 공통 스타일의 최상단 불투명 외부fill과 동일Mercator/camera로 외국지형·문자를 가리고 바다는 단색. 원본과OSM해안 차이는 기록하고 임의보정하지 않는다. 원래 위치판정은 districts 유지.
- 기존 경계출처와 OpenMapTiles/OSM 링크 유지, OpenFreeMap은 My 상세출처에 추가. Geoapify는 검색데이터 출처일때만 표시한다. 자동attribution을 끈 기존렌더러이므로 공통출처가 책임진다.

## 수용
- 단위: 단계hysteresis/명시선택예외/카메라변환/시도별군집/스타일키없음·한국어/원본차폐geometry hash.
- Web: 전국무라벨·지형차폐, 부산/경남/경기/제주 전체fit+실PBF/도로수계/폰트 성공, 타지역사진 이동→재클릭요약, 선택/국가복귀·resize/경계차폐·실패retry·stale기록·비홈 유지. 외국 타일 차폐는 실제pixel도 확인한다.
- Web통과후 Native 새APK의 동일렌더/핀치/사진/단계/문자/카메라/실패를 확인. 타입/export/APK빌드와 실제기능·성능증거를 구분한다. 외부서비스 실제수신 실패는 대역Green으로 대체하지 않는다.
- t14 명세/제품 검토. 사용자 요청으로 관련 변경만 현재브랜치에 commit/push, 원격DB/배포없음.

## 배포 고지 연결
원본 Positron/OpenFreeMap의 copyright·조건·면책 본문을 map-notices.json으로 번들에 포함하고 기존 My 출처의 지도 오픈소스 고지 버튼으로 펼쳐 읽는다. 원문 MD와 번들본문 동일성을 검사한다. 소스 보관만으로 배포 수용으로 계산하지 않는다. configured/export는 부모env 전체를 상속하지만 공개설정 반환/실제runtime은 legacy map key를 참조하지 않는다.
