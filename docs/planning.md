# 🗺️ 지도 기반 개인 여행 기록·탐색 서비스 기획서

## 1. 서비스 개요
* **서비스명 후보**: 여행도감, 여행가자
* **플랫폼**: Android 앱
* **서비스 유형**: 지도 기반 개인 여행 기록·탐색 앱
* **한 줄 소개**: 다녀온 지역을 색칠하고, 사진과 기록을 책처럼 모아보는 나만의 여행도감

> 사용자가 특정 지역을 선택해 그곳에 다녀온 사진과 여행 기록을 남기면, 지도에서 방문한 지역이 색으로 채워집니다. 지역별 진행도와 수집 요소를 통해 여행 기록을 쌓는 재미를 제공하고, 아직 가보지 않은 곳은 랜덤 추천 기능으로 발견할 수 있도록 합니다.

---

## 2. 기획 배경 및 해결하려는 문제
* **배경**: 여행 사진은 휴대폰에 쌓이지만, 장소별로 정리하거나 시간이 지난 뒤 다시 찾아보기가 어렵습니다.
* **문제점**: 여행 기록을 글이나 앨범으로 정리하는 일은 번거롭고 지속하기 어렵습니다.
* **해결책**: 여행 사진과 기록을 지역별로 모으고, 지도 위에 방문 경험을 시각적으로 쌓아 사용자가 자신의 여행 여정을 쉽게 돌아볼 수 있도록 돕습니다.

---

## 3. 주요 사용자 (Target Audience)
* 여행 기록을 남기고 싶지만 정리 과정이 번거로운 사람
* 자신이 다녀온 지역을 지도에서 한눈에 보고 싶은 사람
* 사진과 기억을 책이나 도감처럼 보관하고 싶은 사람
* 새로운 여행지를 재미있고 가볍게 발견하고 싶은 사람

---

## 4. 핵심 사용자 경험 (User Journey)
1. **지역 선택**: 사용자가 국가 또는 지역을 선택합니다.
2. **지도 확인**: 지역 지도가 시·도·구 등 세부 영역으로 나뉘어 표시됩니다.
3. **기록 영역 선택**: 사용자가 여행 기록을 추가할 지역을 선택합니다.
4. **기록 작성**: 사진과 여행 기록을 남깁니다.
5. **시각적 보상**: 방문 기록이 저장되면 해당 지도 영역이 색으로 채워지고 진행도가 올라갑니다.
6. **기록 조회**: 지도에서 지역을 눌러 해당 지역의 사진과 기록을 다시 봅니다.
7. **감상 경험**: 기록을 책장을 넘기듯 감상하거나 사진 중심 화면으로 탐색합니다.

---

## 5. 주요 기능 상세

### 5.1 지역 선택과 여행 기록
* 국가와 지역을 선택해 여행 기록 관리
* 선택한 지역을 행정구역 또는 적절한 지도 단위로 나누어 표시
* 지역별 사진 및 여행 기록 추가
* 지도에서 특정 영역 선택 시 해당 지역의 기록과 사진 표시
* 사진 배열형 화면, 한 장씩 강조하는 화면 등 다양한 감상 방식 검토

### 5.2 지도 색칠과 지역별 진행도
* 여행 기록을 남긴 지역을 지도에서 색으로 채움
* (예시) 부산을 구별 지도로 나누고, 구별 방문 기록을 지도에 반영
* 지역별 수집 현황을 게이지, 도장, 스탬프 형태로 시각화
* 방문할수록 지역별 진행도가 증가하는 수집형 구조

### 5.3 위치 기반 게임 요소
* 방문 기록과 지역 수집을 게임처럼 경험할 수 있는 게미피케이션(Gamification) 요소 도입
* 게이지 완료, 지역 완주 등에 따른 수집 보상 및 성취 표시 검토
* *구체적인 보상 종류와 게임 규칙은 UX 확정 후 상세 설계*

### 5.4 여행지 랜덤 추천
* 사용자가 여행 스타일이나 성향 선택
* 선택 조건에 맞는 여행지를 무작위로 추천
* 랜덤 다트 방식 또는 지도 스포트라이트(특정 장소 강조) 방식 검토
* 추천 결과에서 여행지 사진과 기본 정보 확인 기능 제공
* 추천 장소를 기록 후보 또는 여행 목록에 저장하는 기능

### 5.5 사진과 책 형태의 기록 감상
* 지도를 터치하여 해당 지역의 사진과 기록 조회
* 사진 배열형 / 스포트라이트(한 장씩 보기) 방식 검토
* 책장을 넘기듯 여행 기록을 읽는 리더 UI 검토
* 지도 탐색과 기록 감상 간의 자연스러운 UX 연결

## 6. 디자인 방향성
* **핵심 모티브**: 책, 도감, 지구본, 여행 지도
* **앱 아이콘**: 책 아이콘 또는 책과 지구본을 결합한 형태로 구상
* **컨셉**: 방문 지역을 채워가는 수집형 도감 형태로 지도 표현
* **무드 및 톤앤매너**: 치이카와풍의 귀엽고 따뜻한 분위기 참고 (복제가 아닌 고유 캐릭터 및 시각 요소 자체 제작)
* *지도 커스터마이징 및 테마 기능은 후속 검토*

## 9. MVP (Minimum Viable Product) 제안
첫 버전은 핵심 가치 검증을 위해 최소 범위로 개발합니다.

* **MVP 개발 범위**:
  * Android 전용 App
  * 한정된 지역 지도 및 세부 구역 표시
  * 지역별 사진·기록 작성 및 저장
  * 기록 구역 지도 색칠 및 진행도 표시
  * 지도 기반 기록 조회
  * 기록 감상 UI 1종선택 구현 (책 넘김형 or 사진 배열형)
  * 소규모 데이터 기반 랜덤 추천 시범 제공
* **MVP 성공 기준**: 
  > 사용자가 여행 기록을 지역에 간편하게 연결하고, 지도가 채워지는 visual feedback을 얻으며, 지도에서 해당 기록을 원활히 재탐색할 수 있는가?
