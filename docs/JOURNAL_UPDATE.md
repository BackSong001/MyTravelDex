# 여행가봥 도감과 편집 개편

| 요구사항 | 제품 동작과 검증 기준 |
| --- | --- |
| FR-JOURNAL-REFRESH-01 | 도감은 여행 기록과 스탬프로 구성한다. 홈과 도감에서 파생 퍼즐을 제거하며 스탬프 이력은 유지한다. 본인 기록의 행 메뉴에서 정보 수정과 사진 수를 안내하는 삭제 확인을 연다. |
| FR-JOURNAL-REFRESH-02 | 로그인·프로필 설정 후 첫 홈에서 기기별 계정당 한 번 캐릭터 가이드를 제공한다. 홈, 지도 예시와 작성, 발견 피드, 도감·스탬프, MY를 설명하며 건너뛰기·다시 보기를 제공한다. |
| FR-JOURNAL-REFRESH-03 | /my/edit의 이름·소개·사진 초안은 즉시 미리보기에 반영되며 저장해야 계정에 반영된다. 아바타 자르기와 게시 전 사진의 자르기·회전은 원본 파일과 원래 촬영 정보를 보존한다. |
| FR-JOURNAL-REFRESH-04 | 설정에서 한국어·영어, 화이트·다크를 기기별로 저장한다. 지도 지형은 기존 색을 유지하고 사용자가 작성한 텍스트는 번역하지 않는다. |
| FR-JOURNAL-REFRESH-05 | 볼빵 다람쥐를 비버로 교체한다. 기존 선택과 상호작용을 이어받는다. |

완료 기록의 정보 편집은 본인 소유 기록에 한해 같은 ID의 날짜·제목·평·가시성·대표 장소를 한 트랜잭션으로 저장한다. 여행 사진과 소셜 관계는 기존 기록을 계속 참조한다. 삭제는 기존 정리 큐를 따른다. 새 언어와 테마는 기기에 저장한다. 운영 배포는 별도로 진행한다.

튜토리얼 전주 사진은 Mobius6의 Jeonju Hanok Village 20230408 008(CC BY-SA 4.0)을 축소한 예시다. 사진 옆 라이선스 표기에서 Wikimedia 원본으로 이동한다.

스탬프의 모든 지역 탭은 미획득 도안을 회색으로, 획득 도안을 원래 색으로 표시한다. 전용 그림이 없는 지역은 같은 지역 윤곽을 미획득 시 회색, 획득 시 청록색으로 표시한다. 경남의 진주·통영·거제는 각각 판정하고 모은 스탬프 탭은 획득 도안만 보여준다.
