# 여행가봥 워크숍과 출시 범위

## 이번 브랜치에서 사용할 흐름

홈은 내 기록과 퍼즐의 대시보드다. 홈의 작성 버튼과 지도·피드 바로가기로 각 화면을 연다. 피드는 공개 완료된 여행을 시간순으로 둘러보는 곳, My는 작성자 소개·사진 모음·관계를 관리하는 곳이다. 한 기록의 여러 사진·여행 평·장소·날짜를 묶어 보여주는 기존 상세를 여행 이야기의 기본 단위로 사용한다.

홈의 흰 배경에서 초안의 네 모습(안경 다람쥐, 배낭 고양이, 탐험 수달, 볼빵 다람쥐) 중 하나를 선택한다. 이 기기에서 마지막으로 고른 동물을 다음 방문에도 보여준다. 가만히 있을 때는 숨을 쉬고 눈을 깜빡인다. 몸을 누르면 손을 흔들어 인사한다. 사진 찍기와 뛰놀기는 별도 버튼으로 언제든 다시 재생할 수 있다. 동작 줄이기에서는 각 반응을 정지 자세와 문구로 전달한다. 사진 찍기는 캐릭터 놀이로 동작한다.

앱 시작과 지도 탭 진입 시 가방과 ‘여행가봥’을 표시한다. 동작 줄이기를 존중하고 앱의 로컬 준비 및 지도의 유효한 첫 레이아웃을 기다린다. 지도 진입은 대기 화면을 먼저 그린 뒤 무거운 지도를 마운트한다. 탭을 떠나면 예약 작업을 취소한다. 느린 타일·기록 조회는 각 화면에서 별도로 처리한다.

국내 상세는 숲과 공원의 면 채색을 생략하고 물길과 도로를 유지한다. 해외 지도는 북한·중국·일본의 Natural Earth 해안선·국경과 광역 경계를 대한민국 개요와 같은 육지색·경계색으로 그린다. 탐색 화면의 네 모서리를 동경 72~155도·북위 14~55도 안에 두도록 화면 크기에 맞춰 최대 축소와 이동을 제한한다. 범위 밖 기존 기록·장소 보정은 원좌표의 핀을 유지한다. 주변국 해안의 만·곶과 내륙 경계의 굴곡은 지역 확대에서도 원자료 형태를 보존한다. 광역 경계 자체에는 지명을 붙이지 않고 국가·대표 도시만 충돌을 피하여 표시한다. 대한민국 행정·사진 소속 판정과 저장 좌표는 기존 자료를 사용한다.

## 태그 분류와 아이콘 시안

[태그 아이콘 시트](design/travel-theme-icons.svg). 24단위 그리드에 동일한 두께의 선을 사용하고, 색을 구분하기 어려운 경우에도 형상과 한글 이름으로 식별한다.

| 분류 | 기본 태그 | 아이콘 모티브 |
|---|---|---|
| 자연 | 산, 바다 | 산등성이, 두 줄의 물결 |
| 휴양·활동 | 온천, 낚시 | 김이 나는 탕, 낚싯바늘 |
| 생활·문화 | 도시 산책, 음식 | 건물과 길, 그릇과 젓가락 |

기본 태그와 사용자가 직접 입력한 태그는 이후에 구분한다. 태그 저장·검색·추천, 사진 AI 분석은 이 버전의 기능에 포함하지 않는다. AI 태그를 검토할 때에는 사용자 확인 전 공개 여부와 사진 처리 동의를 먼저 결정한다.

## 워크숍 시연과 출시 판단

1. 사진 두 장으로 여행을 작성하고, 촬영일·대표 장소와 공개 여부를 확인한다.
2. 내 지도에서 여행을 다시 열고, 해외 지도로 이동해 국가와 광역 경계의 차이를 보여준다.
3. 공개 피드·My·퍼즐에서 같은 기록이 어떻게 쓰이는지 시연한다. 비공개 기록은 본인 화면으로만 시연한다.
4. 산·바다 이벤트는 산책이나 바다 기록 수집 같은 주제부터 검토한다. 참여 판정과 위치 공개 범위, 이벤트 운영 주체를 먼저 확정한다.

발표 자료의 순서는 사용자 문제 → 여행 작성 시연 → 탐색·공유·수집 → 다음 실험이다. 제출 후보에서 Android 로그인·사진 권한·재진입·지도 대체 표시를 점검한 뒤 스토어 제출일과 홍보일을 결정한다. 회의의 14일은 일정 가정이며 심사 완료일을 확정하지 않는다. 여행 동물들은 현 버전 안내 캐릭터로 쓰고 최종 종·이름·어원, PWA 전환, 광고, AI·게임형 이벤트는 검토 과제로 둔다.
