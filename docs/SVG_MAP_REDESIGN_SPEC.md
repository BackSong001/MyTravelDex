## 구현 책임과 지정 리뷰 보강
- `regions.ts`가 실제 코드·경계 포함·hole·중복 우선순위·투영을 소유한다. 스탬프와 기존 KR-* 호환은 같은 판정으로 부모코드를 매핑한다. 원자료 개별 geometry는 유효하나 극소 겹침 7개가 있어 단순화/임의 보정 없이 병합만 수행한다. 원본 면적합과 union의 차이는 약 2.07e-10 degree²다. 번들 JSON 5,882,683 + 11,898,583 bytes이며 실행시간/기기 수용은 별도 측정한다.
- `SvgTravelMap.tsx` 공통 렌더러를 Web/Native 진입점이 공유한다. touch ID 집합 변화 때 최신 projection으로 시작점을 다시 잡고 다중터치 후 release를 위치 선택으로 처리하지 않는다. 검색 후보 핀은 현재 화면 투영점의 근접 hit test로 기존 `onSelect` 상세 요청을 재사용하며 빈 캔버스만 역투영 보정한다. 화면 크기/탐색이 원좌표를 저장하지 않는다.
- Home 소유 navigation snapshot은 시도·시군구·camera·지역버튼/기록목록 offset을 복원하고 owner 전환과 대한민국만 초기화한다. 시군구 도감 전달은 기존 권한 rows 이후의 `districtFilter`와 `regionAt`이며 다른 검색/정렬/범위/초안 상태를 유지한다. 홈 상세 진입은 home origin으로 돌아온다.
- 좁은 화면은 지도 위/아래 탐색, 가로·데스크톱은 지도와 지역 목록 두 열이다. Web Home/작성 frame은 같은 최대 1100px이며 이전 MapLibre용 높이비례 폭 제한은 종료한다. 전체 경계는 남은 실제 canvas 안에 맞추고 사용자 카메라는 resize 시 유지한다.
- MapLibre와 30테마·사진 군집·해양 장식 전용 코드를 종료한다. 이전 전용 검사 `maps/map-layout/themes/theme-storage`와 ocean/shadow는 SVG 실제 경계·탐색·좌표·복귀 검사로 대체한다. 사진 저장/서명URL/후보 상세/내 방문/권한/작성·달력·프로필·친구 검사는 유지한다. 원본 PNG/이전 경계와 과거 실행 이력은 보존한다.

### SVG 상세 읽기 재진입 경계
지역/도감/My의 상세 조회는 navigation 세대와 읽기 operation 소유권으로 종료한다. 홈 이동·새 작성·새 상세 읽기에서 이전 상세 읽기만 무효화하고 새 읽기를 허용한다. 이전 성공/실패/finally는 새 화면·오류·busy를 변경하지 않는다. 저장/삭제/사진선택의 mutation busy는 이 취소 대상이 아니며, mutation 진행 중 새 상세 요청은 세대 변경 전 거절한다. 실제 요청을 취소하지 못해도 이전 요청의 후속 요청/UI 적용을 중단한다. save/mutateSelected 내부 상세 재조회는 mutation 소유권을 유지한다.
