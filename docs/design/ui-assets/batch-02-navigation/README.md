## 제작 기준

기존 Batch 01의 백팩 PNG를 실제 스타일 참조로 전달해 내장 `image_gen` 도구로 아이콘을 각각 생성했다. 프롬프트 원문은 [prompts.json](prompts.json)에 보관한다. 코랄 `#F59E8C`, 크림 `#FFF4E8`, 민트 `#BBDDD0`, 하늘 `#A9DFFA`와 둥근 클레이 질감·왼쪽 위의 부드러운 조명을 이어간다. 글자·미세 장식을 줄이고 단일 집·책·더하기·두 사람·한 사람의 실루엣으로 구분한다.

생성 원본은 수정하지 않고 복사했다. 축소판과 검토 이미지만 별도로 생성했다. 생성·렌더링 도우미는 저장소 밖에 두었고 앱 코드나 프로젝트 의존성에 추가하지 않았다.

## Figma 구성

- 별도 페이지에 재사용 가능한 아이콘 원본 컴포넌트 5개를 만들었다. 원본 컴포넌트는 검토 보드 밖에 두고, 보드에는 45개의 인스턴스로 원본·크기별·메뉴 배치를 표시한다.
- 컴포넌트 크기는 96×96이며 이미지 채우기를 사용해 24·32·48·96px에서 내부 그림이 함께 축소된다. 래스터 그림 내부의 색상·형상을 벡터처럼 직접 편집할 수는 없다.
- 하단 순서는 홈·여행도감·+·친구·My다. 기본 메뉴 아이콘은 32px, 중앙 추가 액션은 54px, 메뉴 영역은 높이 84px로 검토했다.
- 홈 선택은 320px, 여행도감·친구·My 선택은 390px 폭으로 배치했다. 선택 상태는 민트 면·진한 글자·밑줄을 함께 사용한다. `+`는 기록 추가 액션이며 선택된 탭 상태를 추가하지 않는다.
- 반복되는 라벨에는 Noto Sans KR 11px Regular/Bold 텍스트 스타일을 적용했다. 필요한 색상만 원시 변수 8개와 의미 별칭 8개로 정리해 배경·글자에 연결했다. 이 변수와 WEB 표기는 Figma 검토용이며 앱 소스에 CSS 변수를 추가하거나 연결하지 않았다.
- 기존 Batch 01 페이지·홈·자산은 변경하지 않았다. 컴포넌트 발행·라이브러리 공개는 하지 않았다.

## 검토 결과와 범위

[quality-report.json](quality-report.json)에 실제 해상도·투명 알파·가장자리 접촉·파일 해시를 기록했다. 5개 원본 모두 실제 투명 영역이 있고 유효 실루엣이 캔버스 가장자리에 닿지 않는다. 24·32·48·96px 크기별 실루엣을 직접 확인했다. 작은 크기에서는 클레이 표면 질감·책갈피 등의 세부 묘사가 줄어든다.

Figma 최종 렌더링을 직접 확인해 아이콘·라벨·선택 표시의 잘림과 겹침을 검토했다. 원본 컴포넌트 5개의 이미지 채우기, 변수 별칭·범위·코드 표기, 반복 라벨의 텍스트 스타일 연결도 확인했다. Figma 객체 식별자는 [figma-state.json](figma-state.json)에 보관한다.

이 작업은 시각 자산 제작과 정적 디자인 검토다. 실제 터치 영역·화면 읽기·상태 전환·기기 배율·아이콘 비텍스트 대비 등 앱 접근성 수용 검증은 수행하지 않았다. 기본 소스·API·DB·환경변수·기존 디자인 원본은 변경하지 않았고 커밋·푸시·배포도 수행하지 않았다.

추가 수정 시 기존 원본을 덮어쓰지 않고 `v2`로 보관한다.
