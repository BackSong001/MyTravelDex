## 새로운 시각 방향

- 흰 바탕 `#FFFFFF`, 차가운 종이색 `#F3F6FB`, 짙은 잉크 `#172D4A`, 코발트 `#254DC4`, 연한 블루 `#E8EFFB`, 그림의 오렌지 `#ED9B6B`를 사용했다.
- 제목·이름·지역명은 Noto Serif KR Bold, 정보와 조작 문구는 Noto Sans KR를 사용한다. 기존의 둥근 클레이 표현에서 명조 제목·사각 사진·얇은 선·우편 테두리로 전환했다.
- 인물과 여행 그림, 부산 갈매기·서울 은행잎 스탬프는 이번 작업에서 내장 image_gen으로 각각 새로 생성했다. 메뉴 아이콘은 새 선형 SVG를 Figma 벡터로 만들었다.
- 프로필 사진과 이름을 좌우로 배치하고 방문 지역 수를 원형 인장으로 표현했다. 아래에는 개인 팔로잉·프로필 공개, 여행 기록·스탬프 진입을 정리했다.
- 스탬프는 기존 작은 칩 격자를 쓰지 않고 실제 지역 윤곽과 해당 지역 상징 그림을 한 쌍으로 배치했다. 모든 지역과 모은 스탬프를 나누어 탐색하는 구성이다.

## 초안의 해석과 기존 기능 경계

초안의 친구 추가 영역은 기존 일방 팔로우에 맞춰 본인 팔로잉 진입으로 표현했다. 원형 배지는 완료한 본인 여행에서 방문한 지역 수를 나타내며 새 보상·선물·레벨 체계를 구현한 것이 아니다. 초안의 나이 항목은 새로운 개인정보 필드로 추가하지 않고, 여행자 이름과 스탬프 정보로 재구성했다. 국가 구분 영역은 현재 지원하는 대한민국 17개 시·도 범위로 표현했다. 미국·일본 스탬프 데이터나 해외 행정 경계를 생성·구현한 것으로 보이지 않도록 했다.

프로필 공개와 여행 기록 공개는 별개다. 본인 화면에서는 공개 여행과 나만 보기 여행을 모두 예시로 보여주며, 프로필을 꺼도 여행 기록 공개 범위가 자동으로 바뀌지 않는다. 방문자 화면은 공개 프로필이 켜진 경우를 가정했고 공개 완료 여행 한 개만 표시한다. 본인 전용 팔로잉 수·지역 방문 수·스탬프·비공개 서울 기록은 방문자 화면에 넣지 않았다. 실제 RLS나 공개 projection을 변경하지 않았다.

이번 프로필 사진은 새 비주얼을 검토하기 위한 가상 인물이다. 실제 인물·사용자 사진이나 계정 데이터를 사용하지 않았다. 기본 아바타의 실제 앱 적용 방식이나 사진 업로드 기능을 변경하지 않았다. 상단 메뉴·수정·공개 전환·팔로우·탭은 시각 제안이며 실행되는 앱 동작이 아니다.

## 지리 데이터와 검토

지역 윤곽은 KOSTAT 2018 / southkorea-maps의 저장소 내 단순화 자료를 사용했다. 자세한 출처·이용 조건은 `frontend/src/data/README.md`를 따른다. 17개 지역 벡터의 원본 경로를 복제하고 같은 비율로 확대·축소했으며, 지역 모양을 AI로 생성하거나 개별 꼭짓점을 바꾸지 않았다. 이번에는 선·색·배치를 새로 정의했다. 최신 행정 경계나 길 안내 자료가 아니다.

모든 비교판과 전체 지역 카탈로그를 렌더링해 프로필·스탬프 테두리·지역명·메뉴·짧은 문구를 검토했다. 미획득 안내의 줄바꿈과 지역별 선 굵기를 v2에서 정리했다. 인물·스탬프 3개는 투명 픽셀이 있는 실제 알파 채널을 확인했고, 스탬프 외곽 테두리의 여백과 프로필 사진의 얼굴·머리 잘림을 시각 확인했다. 생성 이미지의 약한 알파 가장자리는 원본대로 보존했다.

[quality-report.json](quality-report.json)에 화면 구조·알파·지리 경로 보존 근거를 기록했다. 8개 화면 모두 이전 컴포넌트 인스턴스를 사용하지 않았고, 이미지 채우기는 이번에 만든 5개만 사용했다. 텍스트·윤곽·아이콘·스위치·목록·메뉴는 Figma에서 독립 편집할 수 있으며, 전체 UI를 한 장의 PNG로 채우지 않았다. 루트 영역 넘침 없음, 하단 메뉴 순서, 전체 지역 17개, 방문자에게 비공개 샘플·본인 통계가 표시되지 않는 구성을 구조 검사로 확인했다.

정적 시안이며 실제 프로필 저장·검색·팔로우·스크롤·접근성·글꼴 확대·스탬프 집계·Android 동작 검증을 수행한 결과가 아니다. 변경은 이 폴더와 이전 Batch 09 README의 후속 안내에 한정한다. 기본 앱 소스·API·DB·환경변수·원본 스토리보드·컬러 JSON·기존 자산은 보존했고 커밋·푸시·main 병합·배포하지 않았다.
