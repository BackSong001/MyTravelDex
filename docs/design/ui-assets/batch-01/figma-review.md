## 구성

원본 투명 PNG 8종을 각각 이미지 레이어로 업로드하고 한글 이름·파일명과 함께 배치했다. 프로필은 32·48·96px 원형 크롭, 지도 장식은 48·96px 크기로 나란히 검토할 수 있다. 각 묶음은 오토레이아웃을 사용한다. 새로운 앱 화면이나 프로토타입 코드는 작성하지 않았다.

홈 시안은 전체 화면을 하나의 이미지로 업로드하지 않았다. 기존 SVG에서 글자·사진을 분리해 지도·도형을 벡터로 가져온 뒤, 텍스트와 개별 생성 자산·사진을 별도 레이어로 배치했다. 홈 프레임에는 편집 가능한 텍스트 16개와 벡터 57개가 있다. 기존 경계 좌표와 전주 마커의 기준 좌표는 유지했다. 사진 마커와 충남 지역명이 겹쳐 지역명 표시 위치만 위로 조정했다.

Figma에 맑은 고딕이 없어 사용 가능한 `Noto Sans KR` Regular/Bold를 확인해 사용했다. 저장소에 대응하는 Code Connect 및 공개 여행가봥 컴포넌트·변수·스타일은 발견되지 않아 기존 프로젝트의 파스텔 팔레트와 정적 시안 치수를 사용했다. 별도 UI 라이브러리를 추가하지 않았다.

## 검토 결과

Figma에서 렌더링한 `figma-board-v1.png`를 직접 확인했다. 자산 카드·안내문·홈·축소 검토판 사이의 겹침을 수정했고, 최종 이미지에서 전체 자산과 하단 메뉴·지역명·사진·출처 표시를 확인했다. 개별 PNG는 실제 투명 배경이고 홈의 지도와 텍스트는 편집 가능하다. 그림 자체는 래스터 자산이며, 3D 메시나 편집 가능한 캐릭터 벡터가 아니다.

이 결과는 정적 디자인 검토다. 앱 동작·접근성·Android·반응형 수용 검증을 의미하지 않는다. 기본 소스·API·DB·환경변수·기존 디자인 원본은 변경하지 않았다. 자동 커밋·푸시·배포는 수행하지 않았다.
