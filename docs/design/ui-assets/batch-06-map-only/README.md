**홈의 본문은 지도만 보이도록 정정했다.** 사진 카드·기록 목록·홍보 제목·도감 필터를 홈 본문에 배치하지 않는다. 헤더·표시 범위 선택·지도 조작·출처·홈·여행도감·+·친구·My 메뉴만 남겼다. 태블릿도 같은 구성이다.

이전 웹 참고 시안의 3개 색감은 지도 전용 화면으로 다시 만들었고, 새 테마 21개를 추가했다. 총 24개 테마의 모바일 화면 24장(390×844), 대표 테마 태블릿 화면 6장(768×1024)이다. 이전 결과는 이력으로 보존하며 이번 지도 전용 구성을 후속 홈 시안의 기준으로 삼는다.

## 표현 방식

- flat: 부드러운 단색 시·도와 조용한 바다색.
- clay: 시·도별 미세한 명암과 얕은 그림자로 클레이 입체감 제안.
- glass: 밝고 투명한 느낌의 그라데이션. 실제 반투명 지도나 배경 블러 기능을 구현한 것은 아니다.
- foil: 밝은 진주빛 그라데이션. 실제 반사·홀로그램 애니메이션은 없다.
- neon: 어두운 바다·색 경계·제한된 발광 그림자.
- jewel: 어두운 바탕과 보석 계열 지역색·얕은 명암.
- paper: 차분한 종이색·얇은 잉크 경계. 새 종이 텍스처 이미지는 생성하지 않았다.
- ink: 한 색상 계열의 밝기 차와 얇은 윤곽.
- toy: 선명한 지역색·또렷한 윤곽·단단한 아래 그림자.

지역 모양을 재생성하지 않고 Figma의 기존 벡터에 색·그라데이션·윤곽·그림자를 적용했다. 17개 벡터 경로가 복제 시 원본과 같은지 확인한 뒤, 지도 전체를 동일 비율로 확대했다. 지역을 따로 이동하거나 단순화하지 않았다. 라벨은 지도의 원래 배치를 재사용했다. 그림자·발광은 지형 데이터가 아닌 시각 효과다.

기록 미리보기가 닫힌 상태의 지도 색감 비교용 시안이다. 실제 기록·사용자 위치·프로필을 조회하지 않았고 사진 마커와 방문 통계를 꾸며 넣지 않았다. 기록 열기나 기존 상세 기능의 삭제·정책 변경을 구현한 결과는 아니다.

## 재사용 자산과 원본

- 지도: KOSTAT 2018 / southkorea-maps의 기존 17개 단순화 행정 경계. 출처·기준 연도·정확도 한계를 유지한다. 상세 이용 조건은 저장소 `frontend/src/data/README.md`를 따른다.
- 아이콘: Batch 02의 파스텔 컴포넌트와 Batch 03의 네온·포근한 소동물·감성적인·화려한·밝은 래스터 자산을 재사용했다. 이번 묶음의 새 결과는 지도 테마와 화면 구성이다.
- 글꼴: Noto Sans KR Regular/Bold. 폰트 파일은 배포하지 않는다.
- 팔레트: [catalog.json](catalog.json)에 실험용 색상·표현 조건을 기록했다. 앱의 컬러 JSON이나 theme 파일에는 적용하지 않았다.

## 검토 상태

개별 화면 30장, 모바일 모아보기 6장, 태블릿 모아보기 2장, 전체 모아보기 1장으로 PNG 총 39장이다. 모든 비교판을 렌더링해 한글·지역명·경계·메뉴와 의도하지 않은 잘림을 검토했다. 30개 원본 화면 모두 행정 경계 17개·같은 메뉴 순서·기록 패널 부재·루트 영역 넘침 없음을 구조 검사로 확인했다. [quality-report.json](quality-report.json)에 결과를, [figma-state.json](figma-state.json)에 편집 노드 ID를, [manifest.json](manifest.json)에 파일 해시·크기를 기록했다.

Figma 화면은 텍스트·지도 벡터·도형·개별 아이콘이 분리된 편집 가능한 레이어다. 전체 UI를 하나의 PNG로 채우지 않았다. 정적 시안이므로 실제 확대/축소·조회 범위·위치 권한·사진 기록·반응형·글꼴 확대·접근성·Android 기능 검증 완료로 기록하지 않는다.

기본 앱 소스·API·DB·환경변수·기존 SVG·스토리보드·색상 원본은 변경하지 않았다. 변경은 이 폴더와 이전 Batch 05 README의 후속 정정 안내에 한정한다. 커밋·푸시·main 병합·배포를 수행하지 않았다.
