## 이용약관과 개인정보 동의 문안

약관을 열었다는 사실, Google OAuth 승인, OS 위치·사진 권한은 각각 별개다. 현재 앱이 제공하는 것은 **로그인 화면과 설정에서 문서를 열람하는 경로**다. 출시 전 어떤 항목에 동의가 필요한지 처리 근거별로 확정한다. 다음은 가입 화면에 사용할 문안 후보이며 이미 수락한 것으로 간주하지 않는다.

## 공개 페이지 운영

개인정보처리방침, 이용약관, 삭제 안내, 아동 안전 기준만 별도 공개 브랜치 `legal-pages` 루트에 배포한다. 원본은 작업 브랜치 `legal/`이다. 앱·웹은 동일한 고정 HTTPS 주소를 연다. Notion은 하위 문서가 함께 공개되거나 작성자 정보가 메타데이터에 들어갈 수 있어 이번에는 독립적인 정적 HTML을 선택했다. [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages) · [Notion 공개 범위](https://www.notion.com/help/public-pages-and-web-publishing)

고칠 때는 `legal-pages`를 별도 worktree에 체크아웃하고 `legal/`의 HTML/CSS만 루트에 동기화한다. 삭제한 문서도 확인하고 `.nojekyll`을 유지한다. 변경 파일을 검토한 후 해당 브랜치만 커밋·푸시한다. 설치 파일, 앱 소스, 내부 등록 가이드, 환경 파일, 사용자 자료는 게시하지 않는다. 배포 뒤 로그인 없는 브라우저로 링크와 메일 수신 경로를 확인한다. 앱 출시 전 문서의 '출시 준비판' 표시를 실제 적용일 및 변경 이력으로 교체한다.
